# NITRR Digital Twin

NITRR Digital Twin is an interactive campus intelligence platform
designed for National Institute of Technology Raipur.

## Project Status

Under Development.

## Planned Features

- Authentication
- Campus map
- Campus locations
- Events
- Resource availability
- Smart Finder
- Resource sharing
- Issue reporting
- Campus activity
- Campus pressure analysis
- Admin dashboard
- Analytics
- Real-time updates

## Technology

- React
- Node.js
- Express
- MongoDB
- Socket.IO
- Leaflet
- Recharts
